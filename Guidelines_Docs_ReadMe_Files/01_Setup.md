Step 1: Install Visual Studio App
Step 2: Install Node.js and npm, if it's not installed in your system. You can check if Node.js and npm are installed by running the following commands in your terminal or command prompt: 
	The commands to check - "node -v" and "npm -v". It shows the version of Node.js and npm installed on your system. If you see a version number, it means Node.js and npm are already installed. If not, you need to install them.
	To install Node.js and npm, follow these steps:
	1. Go to the official Node.js website: https://nodejs.org/
	2. Download the LTS (Long Term Support) version for your operating system.
		click on "Get Node js" button, then click on "Windows Installer" or "macOS Installer" depending on your OS.
	3. Run the installer and follow the prompts to complete the installation.
Step 3: Install Git 
	1. Go to the official Git website: https://git-scm.com/
	2. Download the version for your operating system -> Standalone Installer based on the system type of your laptop/machine (32-bit or 64-bit).
	3. Run the installer and follow the prompts to complete the installation.
	4. introduce yourself to Git by running below commands in Terminal or Command Prompt to set your username and email address for Git commits:
		a. git config --global user.name "Your Name"
		b. git config --global user.email "your.email@example.com"
		c. git config --list
Step 4: Close your terminal or IDE completely and reopen it.
