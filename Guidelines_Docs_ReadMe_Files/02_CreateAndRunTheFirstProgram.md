Create any simple program in your preferred programming language. For example, you can create a "Hello, World!" program. 
Steps to create a program and Run in JavaScript:
1. Create any new folder
2. Open the folder in Visual Studio Code
3. Create a new file with a .js extension (e.g., hello.js)
4. Write your JavaScript code in the file
5. Save the file
6. Open the terminal in Visual Studio Code
7. Navigate to the folder where your JavaScript file is located using the `cd` command in the terminal. For example, if your file is in a folder named "01_Chapter_JS_Basics", you would run: `cd C:\Users\..\01_Chapter_JS_Basics`
8. Run the program using the command: `node 01_HelloWorld.js`
